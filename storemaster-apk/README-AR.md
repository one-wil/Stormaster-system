# STOREMASTER Dashboard — Android APK

هذا المشروع يحوّل ملف لوحة التحكم `index-93.html` إلى تطبيق Android بسيط باستخدام WebView، مع إبقاء واجهة لوحة التحكم ومنطقها داخل التطبيق.

## بناء APK عبر GitHub Actions

1. أنشئ مستودع GitHub جديدًا باسم `StoreMasterDashboard`.
2. ارفع **محتويات هذا المجلد** إلى المستودع، بما فيها مجلد `.github`.
3. افتح تبويب **Actions** في GitHub واسمح بتشغيل Actions إذا طُلب ذلك.
4. شغّل سير العمل **Build STOREMASTER APK** من زر **Run workflow**، أو ادفع commit جديدًا إلى `main`.
5. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى **Artifacts** ثم نزّل `StoreMaster-APK`.
6. فك ضغط الملف المنزّل وثبّت `app-debug.apk` على هاتف Android. قد تحتاج إلى السماح بالتثبيت من هذا المصدر.

## ملاحظات مهمة

- التطبيق يعرض لوحة التحكم المرفقة محليًا، ولذلك تظل الواجهة قابلة للفتح دون اتصال؛ لكن عمليات Worker وإنشاء المتاجر وفحص Cloudflare تحتاج إلى الإنترنت وإعدادات Worker الصحيحة.
- بيانات لوحة التحكم وإعداداتها تُحفظ في مساحة WebView المحلية على الهاتف. حذف بيانات التطبيق قد يحذف هذه البيانات؛ استخدم زر **Exporter** للاحتفاظ بنسخة احتياطية.
- شاشة الرقم السري الموجودة في ملف HTML هي حاجز واجهة فقط وليست مصادقة قوية. لا تعتبرها بديلًا عن حماية الخادم. كذلك لا تشارك ملف APK مع أشخاص غير موثوقين إذا كانت إعدادات Worker الحساسة محفوظة على الجهاز.
- هذا البناء هو **APK تجريبي موقّع بمفتاح debug من GitHub Actions**، وليس إصدارًا موقّعًا للنشر التجاري على Google Play.
